продолжить другой агент. Не включайте credentials, cookies, media URL и полный DataStore.

## Правила хорошего handoff

- Указать последний действительно успешный command/result.
- Не писать «всё работает», если playback/focus проверен только сборкой.
- Разделять подтверждённое кодом, unit test и real-device evidence.
- Записать временные test files/packages и удалить их до передачи, если это безопасно.
- Если был изменён пользовательский progress, указать точный targeted cleanup status.
- Не предлагать следующему агенту читать огромный raw log вместо краткой причины.
- Сослаться на профильные документы из `docs/README.md`.
