# Контракт интерфейса Android TV

Этот документ — источник истины для текущего визуального языка и TV-навигации
KinogoATV. Он описывает реализованный дизайн ветки `0.5.3`, а не ранние рендеры и не
целевой макет «на будущее». При намеренном изменении любого перечисленного ниже контракта
код, тесты и этот файл должны обновляться в одной задаче.

Последнее обновление: **26 августа 2026 года**.

## Базовые условия

- Интерфейс рассчитан только на горизонтальный Android TV, минимум API 28.
- Все основные сценарии обязаны работать обычным D-pad-пультом без аэромыши.
- Экран используется от края до края. Глобальных декоративных safe-area-полей нет; рабочий
  контент получает только компактные отступы `start = 14 dp`, `top = 10 dp`, `end = 10 dp`,
  `bottom = 6 dp`.
- Меню всегда фиксировано слева и не всплывает поверх открытого раздела.
- Фокус должен быть однозначно виден с дивана, но не должен превращать каждый элемент в
  тяжёлую карточку с несколькими рамками.
- Общие action/chip/icon-кнопки и строки настроек при фокусе используют контрастную заливку,
  белую рамку `3 dp` и тень. Постеры сохраняют отдельный существующий focus treatment,
  чтобы это усиление не меняло геометрию каталожной сетки.

## Каркас и левая панель

- Ширина панели постоянна: `174 dp`.
- Панель занимает полную высоту и имеет сплошной фон `#17262E`, без внешней рамки и тени.
- Шапка логотипа имеет высоту `52 dp`, обычный пункт — `44 dp`, нижний индикатор состояния —
  `32 dp`.
- Элементы расположены у левого края с небольшими внутренними отступами; между пунктами
  используется интервал `3 dp`.
- Сфокусированный пункт залит бирюзовым и имеет белый левый маркер. Активный, но
  несфокусированный раздел остаётся различим за счёт спокойной полупрозрачной заливки.
- Стрелка вправо переводит фокус из панели в текущий раздел. Стрелка влево из первого
  столбца или управляющей строки должна возвращать фокус в панель.
- При cold start без восстанавливаемой карточки первым фокус получает выбранный пункт
  rail. Home, Catalog, Search, History и Settings не должны перехватывать его, пока
  пользователь не активировал раздел или контент.

- У TV-плитки нет декоративной нижней полосы.

## Постеры и общие сетки

- Основная сетка любого каталожного раздела содержит ровно шесть колонок
  (`PosterGridColumnCount = 6`), поэтому на экране одновременно видны не менее пяти постеров
  и несколько строк.
- Соотношение сторон изображения постера — `2:3`.
- Горизонтальный интервал сетки — `10 dp`, вертикальный — `12 dp`.
- Тексты карточки компактны: заголовок `13 sp`, вторичная строка `10 sp`; обе строки
  однострочные с ellipsis.
- Фокус постера обозначается бирюзовой рамкой `3 dp`, лёгким увеличением до `1.025` и
  умеренной тенью. Несфокусированный контур — нейтральный стальной `1 dp`.
- Значок качества содержит только значение вроде `WEB-DL 720` или `BDRip`. Префиксы
  `Качество` и `Якість`, включая двоеточие, удаляются перед показом.
- Общая сетка запускает следующую загрузку, когда под строкой сфокусированного постера
  остаётся меньше двух загруженных строк. При шести колонках это означает вход в одну из
  двух последних строк, а не ожидание последней карточки.

## Главная

- Большого hero-баннера нет.
- История на Главной не дублируется: для неё есть отдельный раздел левой панели.
- Отдельного заголовка `Новинки` нет. Сразу под компактной управляющей строкой находится
  общая шестиколоночная сетка текущей главной ленты.
- Управляющая строка повторяет доступные на главной сайта controls: сортировка, отдельное
  направление `↑`/`↓`, подборка, год, страны и сброс. Подборки, годы и страны приходят из
  HTML текущего зеркала, а не из локального списка.
- После первой страницы Главная автоматически цепляет строго возрастающие страницы, пока
  не соберёт минимум 18 уникальных карточек — три строки по шесть. Если сервер раньше
  заканчивает выдачу, загрузка останавливается на доступном количестве.
- Главная не запускает скрытый прогрев Каталога: stateful xSort-сессия остаётся доступна
  видимой ленте.
- Начальный фокус получает первый постер. Up из первой строки позволяет перейти к filters,
  Left из первой колонки — в постоянную левую панель.

## Каталог

- Каталог по умолчанию открывает категорию `Новинки`.
- Прямой переход пользователя в Каталог запускает его загрузку; скрытого предварительного
  запроса из Главной нет.
- Перед сортировкой расположен единый dropdown `Категории`. Он содержит две визуальные
  группы в порядке сайта: `Фильмы` и `Сериалы`; произвольный URL из HTML не становится
  пунктом меню. Если xSort fragment не содержит sidebar, меню остаётся доступным через
  точный fallback из 28 allowlisted категорий; непустой server subset не расширяется.
- Далее в одной компактной строке идут `Сортировать:`, dropdown серверной сортировки,
  отдельная кнопка направления `↑`/`↓`, `Подборка`, `Год`, `Страны` и кнопка сброса `×`.
- Выбор значения в dropdown меняет только само поле. Повторный выбор текущей сортировки не
  переворачивает порядок; направление меняется только отдельной кнопкой.
- Подборка, год и страна могут применяться совместно: это состояние одной origin-scoped
  xSort-сессии. Списки сортировки, подборок, годов и стран берутся со страницы текущего
  зеркала; fallback категорий описан отдельно выше.
- Dropdown открывается по OK/Enter, фокусирует текущий пункт, полностью управляется D-pad и
  закрывается Back. После выбора или закрытия фокус возвращается на вызвавшую кнопку.
  Активные элементы используют тот же бирюзовый фокус, что и левая панель.

## Поиск

- Автоматический запрос откладывается на `750 ms` после последнего изменения текста.
- Нажатие Enter, IME Search или кнопки подтверждения отправляет запрос немедленно, отменяя
  ожидание.
- После явной отправки экранная клавиатура скрывается, поле ввода теряет фокус, а когда
  результаты готовы, фокус переводится на первый постер.
- Голосовой поиск представлен графической кнопкой микрофона. Текстовая подпись
  `Голосовой поиск` не должна занимать место в управляющей строке; доступное описание
  остаётся в semantics/content description.
- Результаты используют общую шестиколоночную сетку.
- Под строкой ввода показывается одна горизонтальная строка из десяти последних
  подтверждённых запросов. Новый запрос идёт первым, повтор переносится в начало; OK на chip
  немедленно повторяет запрос.
- При открытии Details и возврате Back сохраняются текст, уже загруженная выдача, paging key и
  stable ID последнего сфокусированного постера. Сетка сначала прокручивается к нему и только
  затем возвращает фокус; числовая позиция не сохраняется.
- Когда под строкой фокуса остаётся меньше двух загруженных строк, поиск заранее запрашивает
  следующую серверную страницу того же encoded query и добавляет карточки без сброса
  фокуса.
- Ошибка первой или следующей страницы показывает явное действие `Повторить` для того же
  запроса.

## Общая пагинация и D-pad сетки

Главная, Каталог и Поиск используют один `TvPosterGrid`:

- следующая страница запрашивается, когда под строкой фокуса остаётся меньше двух
  загруженных строк (последняя может быть неполной); для шестиколоночной сетки preload
  начинается в одной из двух последних строк;
- один и тот же query-aware preload boundary срабатывает один раз, поэтому удержание кнопки
  не создаёт дублирующие запросы, а новая выдача может снова загрузить свою следующую
  страницу даже при совпадении крайних ID;
- карточки имеют stable ID; append не запрашивает начальный фокус повторно, не переносит
  его на первый/последний постер и не отменяет уже начатый D-pad-переход к сохранившейся
  карточке;
- автоматическое добирание Главной до 18 уникальных карточек не запрашивает UI-фокус;
  фокус остаётся у текущего постера или управляющего элемента;
- reset той же Home/Catalog-ленты отменяет её устаревшую загрузку; при смене filters на том
  же origin прежние карточки и controls остаются видимыми до успешной замены и после
  transient failure. Search и cross-origin reset очищают прежнюю выдачу;
- Left/Right перемещают фокус только внутри текущей строки и не выполняют wrap; Up/Down
  переходят на индекс в той же колонке;
- Left из первой колонки и Up из первой строки оставляют событие внешнему focus graph, чтобы
  можно было перейти в rail или управляющую строку;
- на неполной последней строке направление без реальной целевой карточки сохраняет текущий
  фокус вместо произвольного скачка.
- переход к соседней строке за границей viewport прокручивает сетку ровно на одну строку,
  а не закрепляет целевой постер вверху экрана.

## Закладки и история

- Закладки и история используют те же размеры постеров, интервалы и фокус, что каталог.
- Карточка истории обязана содержать нормализованный ID контента, название, постер и
  прогресс; технический ID не является допустимой пользовательской заменой заголовка.
- Строка истории может дополнительно показывать сезон, серию, позицию и дату просмотра.
- Короткий `OK` на постере Истории всегда открывает Details. История не имеет отдельного
  прямого маршрута в плеер; `Смотреть`/`Продолжить` выбирается уже в карточке.
- Долгий `OK`/`Enter` и long tap открывают диалог управления выбранной записью: удалить
  материал или перейти к подтверждению полной очистки. Начальный фокус — `Отмена`, `Back`
  равен отмене. Удаление одного сериала означает удаление всех его episode checkpoints.
- После удаления фокус остаётся в том же визуальном slot (следующий, иначе предыдущий
  stable content ID). После очистки или удаления последнего элемента фокус переходит на
  выбранный пункт `История` в постоянном rail; пустой экран не оставляет невидимый focus.

## Настройки

- Экран использует компактные секции и интервалы `3–8 dp` между внутренними элементами.
- Крупная карточка `О программе` является первым focusable-элементом Настроек. Тот же диалог
  открывается по OK на focusable-логотипе KINOGO над пунктами navigation rail.
- Boolean-настройки «Следующая серия», контрастность, уменьшение анимаций и
  автопроверка обновлений показывают явный `Switch` и меняются по OK/Enter.
- Качество, запас буфера, шаг перемотки и субтитры открывают D-pad dropdown. Запас буфера
  предлагает ровно `5`, `10`, `15`, `20` и `30 сек`, по умолчанию `15 сек`. Диалог
  фокусирует текущее значение, а после выбора или Back возвращает фокус на исходную строку.
- Left и Right не меняют значение настройки и не перехватываются её строкой. Они остаются
  навигационными клавишами, в том числе позволяют выйти в левую панель.
- Текстовый маркер `OK` удалён: тип управления виден по Switch либо стрелке dropdown.
- Диалоги аккаунта, зеркал и подтверждения могут быть шире обычной строки, но не должны
  увеличивать плотность всего основного экрана.
- Блок аккаунта предлагает вход и регистрацию. Если DLE сначала возвращает правила,
  Registration dialog показывает их отдельным прокручиваемым шагом. Начальный фокус —
  `Не принимаю`; только явный OK на `Принимаю и продолжить` открывает серверную account form.
- На втором шаге dialog показывает поля и image CAPTCHA, допускает явное обновление
  challenge и не изображает reCAPTCHA/hCaptcha/Turnstile доступными без браузерного flow.
  Sensitive field state намеренно не переживает dismiss/recreation.
- Блок обновлений показывает текущую/доступную версию и одно контекстное действие:
  проверить, загрузить либо открыть системный установщик. UI не обещает silent install.
- Если автоматическая проверка при запуске находит новую версию, тот же state показывается
  глобальным TV-диалогом поверх любого раздела. Безопасный начальный фокус получает
  `Позже`; `Back` откладывает предложение только до следующего запуска, а `Загрузить` ведёт
  в существующую проверку APK и затем в системный Package Installer.
- Все связанные с обновлением элементы сгруппированы в конце Настроек: сначала Switch
  автоматической проверки, непосредственно за ним карточка ручной проверки/загрузки/
  открытия установщика. Между ними не располагаются несвязанные секции.

## Карточка фильма или сериала

- Слева показан крупный постер шириной `205 dp`; изображение использует общее соотношение
  `2:3`.
- Справа находятся название, метаданные, полное описание и действия.
- Первый ряд действий: `Смотреть` или `Продолжить`, `С начала`, `В избранное`.
- Для сериала `Продолжить` указывает новейшую незавершённую единицу и позицию,
  например `Продолжить S03E07 с 17:42`. Завершённая первая серия не маскирует более
  новый незавершённый checkpoint.
- После открытия карточки или возврата из плеера primary playback action получает фокус с
  ограниченным retry на пяти Compose frames, пока LazyColumn подключает target.
- Возврат после обычного выхода или неудачного автоматического восстановления источника
  обязан оставить `Смотреть`/`Продолжить` доступным действием. Карточка не должна требовать
  дополнительного выхода и повторного открытия, чтобы снова разрешить запуск.
- Сразу под ним компактно расположены взаимоисключающие статусы `Не смотрел`, `Смотрю`,
  `Смотрел`, `Буду`, `Бросил`. Отдельного заголовка `Мои закладки` нет.
- Полное описание не обрезается фиксированным количеством строк.
- Постоянного пустого блока `Выбор просмотра` в карточке нет: конкретный выбор выполняется
  после нажатия `Смотреть`.

## Выбор источника перед просмотром

Экран должен без дополнительного прокручивания прятать как можно меньше управляющих строк.
Основные вертикальные интервалы составляют `8–10 dp`, внешние — `24 dp` по горизонтали и
`16 dp` по вертикали.

Порядок выбора и зависимостей:

1. источник;
2. озвучка, доступная для выбранного источника;
3. сезон, доступный для выбранной пары источник + озвучка;
4. серия, доступная для выбранных источника + озвучки + сезона;
5. качество конкретного варианта.

Строка серии обязательна для эпизодического материала и должна быть видна на этом экране:
пользователь может открыть конкретную серию вместо продолжения сохранённой. При изменении
верхнего уровня модель `PlaybackSourceSelectionModel` нормализует все зависимые значения и
не оставляет недоступный сезон, серию, озвучку или качество выбранными.

## Полноэкранный плеер

- Видео всегда полноэкранное; HUD накладывается поверх него на полупрозрачном тёмном фоне.
- OK при скрытом HUD показывает управление и не ставит воспроизведение на паузу.
- Left и Right при скрытом HUD выполняют шаг перемотки и открывают HUD с фокусом на
  таймлайне.
- Таймлайн не получает рамку фокуса. В сфокусированном состоянии текущая позиция отмечается
  белой точкой диаметром `12 dp`.
- Во время Media3 `STATE_BUFFERING` по центру показывается анимированный индикатор в тёмном
  круге. В режиме уменьшения анимации остаётся статическое кольцо.
- Нижняя строка содержит серии; отдельная дублирующая кнопка `Серии` не нужна.
- Управление сериями, сезоном, озвучкой, качеством, субтитрами и Web-fallback доступно из
  HUD обычным D-pad.
- Ручной кнопки `Обновить источник` в native HUD нет. Плеер ограниченно и незаметно
  обновляет источник сам; если восстановление не удалось, пользователь возвращается в
  карточку и явно запускает свежую подготовку кнопкой `Смотреть`/`Продолжить`.
- Выбор фиксированного качества является верхним предпочтительным пределом для текущей и
  следующих серий: используется точное значение, если оно есть, иначе максимальное
  доступное не выше выбранного. Если все доступные варианты выше предела, используется
  минимальный из них. `Авто` оставляет выбор адаптивному потоку; реальный выбранный вариант
  не должен подменять сохранённое пользовательское предпочтение.
- Настройка `Запас буфера` управляет временным резервом Media3 и сохраняется между
  запусками. Плеер применяет новое значение при создании playback session; интерфейс не
  обещает бесконечное накопление памяти или устранение всех provider/network stalls.
- Все совместимые серии выбранных источника и озвучки образуют один упорядоченный Media3
  playlist, включая переходы между сезонами. В памяти заранее держится только
  непосредственно следующая серия: 2,5 секунды для buffer 5 секунд, иначе 5 секунд, и лишь
  когда включён auto-next, playback активен и несупрессирован, remaining не больше target, а
  конец текущей серии уже buffered до `duration - 500 ms`. Pause/suppression/close/backseek
  отключают ранний open; остальные серии и disk cache не прогреваются, отдельного resolver
  warmup нет.
- После последней серии текущего сезона переход `Следующая серия` продолжает воспроизведение
  первой доступной серией следующего сезона по тем же правилам, что обычный переход между
  сериями.
- После естественного окончания фильма или последней доступной серии приложение
  возвращается в карточку материала, а не в каталог, экран выбора источника или выход из
  приложения.

Подробная событийная модель, media keys и resume-контракт описаны в
[`PLAYBACK.md`](PLAYBACK.md) и [`NATIVE_PLAYER_TV_UX.md`](NATIVE_PLAYER_TV_UX.md).

## D-pad anti-regression checklist

После изменения компоновки, размера или порядка focusable-элементов вручную проверить на
реальном TV:

- холодный старт оставляет видимый фокус на текущем пункте rail; экран не перехватывает его;
- Up/Down в панели проходят по всем разделам, OK открывает раздел, активный пункт остаётся
  подсвеченным;
- Right из панели входит в контент, Left из первого столбца возвращается в панель;
- сетка предсказуемо перемещает фокус по шести колонкам, не делает wrap и подгружает
  следующую страницу, когда ниже фокуса остаётся меньше двух строк, без смены текущего
  фокуса;
- Главная: нет истории и заголовка `Новинки`; все server-derived dropdowns и сброс доступны
  пультом, после них идёт единая сетка; стартовая выдача содержит минимум 18 уникальных
  карточек, если сервер располагает таким количеством;
- Каталог: по умолчанию выбраны `Новинки`; объединённые категории, сортировка, отдельное
  направление, подборка, год, страны и сброс полностью управляются пультом; прямой вход
  запускает загрузку без скрытого предварительного запроса из Главной;
- повторный выбор текущего sort option не меняет направление; `↑`/`↓` меняет;
- поиск: следующая страница того же запроса добавляется без скачка фокуса;
- поиск: Enter немедленно отправляет запрос, скрывает клавиатуру и переводит фокус в
  результаты;
- История: короткий `OK` открывает Details, долгий `OK` открывает безопасный delete/clear
  dialog; после удаления/очистки focus остаётся на видимом poster либо пункте rail;
- настройки: OK меняет Switch или открывает dropdown; выбор/Back возвращают фокус в строку,
  Left/Right остаются навигационными;
- startup update: automatic `Available` показывает глобальный dialog с начальным фокусом
  `Позже`; временная ошибка допускает одну задержанную попытку, а Back не отключает auto-check;
- регистрация: rules screen по умолчанию фокусирует `Не принимаю`; accept возможен только
  отдельным OK; Down на нижней границе rules scroll возвращает focus на `Не принимаю`, а не
  запирает его в прокручиваемой области; затем form/CAPTCHA остаются достижимы D-pad;
- карточка: постер виден, все действия и статусы достижимы, описание можно прочитать
  полностью;
- выбор источника: после смены озвучки доступны только её сезоны и серии, строка серии
  достижима;
- плеер: OK открывает HUD, Left/Right фокусируют таймлайн, точка текущей позиции видна,
  остальные кнопки достижимы без аэромыши;
- в native HUD нет ручной кнопки обновления источника; при зависании восстановление
  выполняется автоматически, а после неудачи возврат в карточку оставляет действие
  `Смотреть`/`Продолжить` активным;
- выбранный предел качества сохраняется при переходе между сериями; отсутствие точного
  качества применяет описанное выше правило ближайшего варианта, а не случайный `Авто`;
- настройки: dropdown `Запас буфера` содержит только 5/10/15/20/30 секунд, возвращает фокус
  в строку и после повторного открытия показывает сохранённое значение;
- последняя серия сезона переходит в первую доступную серию следующего, а окончание
  последнего доступного материала возвращает в его карточку;
- preload через границу сезона ограничен только следующей совместимой серией и не должен
  заметно менять HUD, фокус или выбранную episode row;
- Back из Details возвращает в тот раздел, из которого карточка была открыта. Поиск при этом
  восстанавливает запрос, выдачу и последний активный постер. Только Back из корневого раздела
  показывает подтверждение выхода, а не закрывает приложение.
