# Контракт интерфейса Android TV

Этот документ — источник истины для текущего визуального языка и TV-навигации
KinogoATV. Он описывает реализованный дизайн ветки `0.4.0-dev`, а не ранние рендеры и не
целевой макет «на будущее». При намеренном изменении любого перечисленного ниже контракта
код, тесты и этот файл должны обновляться в одной задаче.

## Базовые условия

- Интерфейс рассчитан только на горизонтальный Android TV, минимум API 28.
- Все основные сценарии обязаны работать обычным D-pad-пультом без аэромыши.
- Экран используется от края до края. Глобальных декоративных safe-area-полей нет; рабочий
  контент получает только компактные отступы `start = 14 dp`, `top = 10 dp`, `end = 10 dp`,
  `bottom = 6 dp`.
- Меню всегда фиксировано слева и не всплывает поверх открытого раздела.
- Фокус должен быть однозначно виден с дивана, но не должен превращать каждый элемент в
  тяжёлую карточку с несколькими рамками.

## Палитра

Основная тема стальная с голубыми и бирюзовыми интерактивными элементами.

| Роль | Цвет |
| --- | --- |
| Акцент и активный фокус | `#43D7D2` |
| Текст на акценте | `#10272D` |
| Дополнительный голубой акцент | `#62BFE9` |
| Текст на дополнительном акценте | `#10242D` |
| Основной фон контента | `#304955` |
| Основной текст | `#F5F7FA` |
| Поверхность | `#385562` |
| Вариант поверхности | `#466773` |
| Вторичный текст | `#D1E0E6` |
| Нейтральный контур | `#5D7B87` |
| Фон левой панели и внешних тёмных областей | `#17262E` |

Высококонтрастный режим использует `#72FFF8` для акцента, `#101B20` для фона,
`#1B3039` для поверхности и `#284650` для варианта поверхности.

Красный, жёлтый и зелёный допустимы как смысловые исключения для ошибок, предупреждений и
успешных состояний. Они не заменяют бирюзовый цвет обычного фокуса.

## Каркас и левая панель

- Ширина панели постоянна: `174 dp`.
- Панель занимает полную высоту и имеет сплошной фон `#17262E`, без внешней рамки и тени.
- Шапка логотипа имеет высоту `52 dp`, обычный пункт — `44 dp`, нижний индикатор состояния —
  `32 dp`.
- Элементы расположены у левого края с небольшими внутренними отступами; между пунктами
  используется интервал `3 dp`.
- Активный раздел залит бирюзовым. Сфокусированный, но не активный пункт получает стальное
  выделение; активный раздел остаётся различимым после перехода фокуса в контент.
- Стрелка вправо переводит фокус из панели в текущий раздел. Стрелка влево из первого
  столбца или управляющей строки должна возвращать фокус в панель.

## Логотип, TV-плитка и launcher icon

Брендинг собирается детерминированно скриптом
[`scripts/generate-launcher-assets.ps1`](../scripts/generate-launcher-assets.ps1). Нельзя
заменять его генеративной перерисовкой или вручную создавать расходящиеся варианты.

- Исходная официальная иконка хранится в
  `app/src/main/res/drawable-nodpi/ic_kinogo_original.png`.
- TV-плитка имеет почти чёрный стальной фон, исходную иконку слева, белую надпись `KINOGO` и
  бирюзовую подпись `for Android TV`.
- У TV-плитки нет декоративной нижней полосы.
- Обычная и адаптивная Android-иконка используют исходное изображение с бирюзовой меткой
  `ATV` в правой нижней четверти.
- Панель приложения использует тот же принцип: исходная иконка, `KINOGO`, затем
  `for Android TV`.
- Скрипт выпускает `tv_banner.png`, legacy `ic_launcher.png` и
  `ic_launcher_foreground_atv.png` во всех поддерживаемых density-каталогах. После правки
  композиции нужно запускать скрипт, а не менять отдельный PNG.

## Постеры и общие сетки

- Основная сетка любого каталожного раздела содержит ровно шесть колонок
  (`PosterGridColumnCount = 6`), поэтому на экране одновременно видны не менее пяти постеров
  и несколько строк.
- Соотношение сторон изображения постера — `2:3`.
- Горизонтальный интервал сетки — `10 dp`, вертикальный — `12 dp`.
- Тексты карточки компактны: заголовок `13 sp`, вторичная строка `10 sp`; обе строки
  однострочные с ellipsis.
- Фокус постера обозначается бирюзовой рамкой `3 dp`, лёгким увеличением до `1.025` и
  умеренной тенью. Несфокусированный контур — нейтральный стальной `1 dp`.
- Значок качества содержит только значение вроде `WEB-DL 720` или `BDRip`. Префиксы
  `Качество` и `Якість`, включая двоеточие, удаляются перед показом.
- Каталог запускает следующую загрузку заранее, при входе фокуса в последнюю уже загруженную
  строку, а не после достижения последней карточки.

## Главная

- Большого hero-баннера нет.
- `История просмотра` показывается одной горизонтальной строкой. Она может прокручиваться
  вправо, но не занимает несколько строк.
- `Новинки` идут ниже как шестиколоночная плиточная область в несколько строк. Для неё нет
  отдельного горизонтального пролистывания: весь экран прокручивается по вертикали.
- Начальный фокус получает первый элемент истории; если история пуста — первый элемент
  новинок.

## Каталог

- Верхняя строка содержит четыре раздела: `Все`, `Фильмы`, `Сериалы`, `Мультфильмы`.
- Сортировка открывается как выпадающий список. Сейчас это локальная сортировка уже
  загруженного набора: `Сначала новые`, по названию или по качеству.
- Кнопка `Фильтр` открывает диалог высотой до `82%` и шириной до `80%` экрана.
- В диалоге доступны сброс, новинки, год, страна и жанр. Одновременно применяется только
  один детерминированный серверный GET-фильтр:
  `/novinki/`, `/xfsearch/god/{year}/`, `/xfsearch/country/{country}/` либо подтверждённый
  жанровый путь.
- Нельзя показывать комбинированные фильтры как работающие, пока их серверный контракт не
  подтверждён. Заголовок диалога явно сообщает: `Один серверный фильтр за раз`.
- Активные вкладки, элементы списка и кнопки используют тот же бирюзовый фокус, что и левая
  панель.

## Поиск

- Автоматический запрос откладывается на `750 ms` после последнего изменения текста.
- Нажатие Enter, IME Search или кнопки подтверждения отправляет запрос немедленно, отменяя
  ожидание.
- После явной отправки экранная клавиатура скрывается, поле ввода теряет фокус, а когда
  результаты готовы, фокус переводится на первый постер.
- Голосовой поиск представлен графической кнопкой микрофона. Текстовая подпись
  `Голосовой поиск` не должна занимать место в управляющей строке; доступное описание
  остаётся в semantics/content description.
- Результаты используют общую шестиколоночную сетку.

## Закладки и история

- Закладки и история используют те же размеры постеров, интервалы и фокус, что каталог.
- Карточка истории обязана содержать нормализованный ID контента, название, постер и
  прогресс; технический ID не является допустимой пользовательской заменой заголовка.
- Строка истории может дополнительно показывать сезон, серию, позицию и дату просмотра.

## Настройки

- Экран использует компактные секции и интервалы `3–8 dp` между внутренними элементами.
- Настройка изменяется только по OK/Enter. Одно нажатие выбирает следующее значение
  (`SettingCycleDirection.NEXT`).
- Left и Right не меняют значение настройки и не перехватываются её строкой. Они остаются
  навигационными клавишами, в том числе позволяют выйти в левую панель.
- В правой части изменяемой строки показывается маркер `OK`, а не подсказка со стрелками.
- Диалоги аккаунта, зеркал и подтверждения могут быть шире обычной строки, но не должны
  увеличивать плотность всего основного экрана.

## Карточка фильма или сериала

- Слева показан крупный постер шириной `205 dp`; изображение использует общее соотношение
  `2:3`.
- Справа находятся название, метаданные, полное описание и действия.
- Первый ряд действий: `Смотреть` или `Продолжить`, `С начала`, `В избранное`.
- Сразу под ним компактно расположены взаимоисключающие статусы `Не смотрел`, `Смотрю`,
  `Смотрел`, `Буду`, `Бросил`. Отдельного заголовка `Мои закладки` нет.
- Полное описание не обрезается фиксированным количеством строк.
- Постоянного пустого блока `Выбор просмотра` в карточке нет: конкретный выбор выполняется
  после нажатия `Смотреть`.

## Выбор источника перед просмотром

Экран должен без дополнительного прокручивания прятать как можно меньше управляющих строк.
Основные вертикальные интервалы составляют `8–10 dp`, внешние — `24 dp` по горизонтали и
`16 dp` по вертикали.

Порядок выбора и зависимостей:

1. источник;
2. озвучка, доступная для выбранного источника;
3. сезон, доступный для выбранной пары источник + озвучка;
4. серия, доступная для выбранных источника + озвучки + сезона;
5. качество конкретного варианта.

Строка серии обязательна для эпизодического материала и должна быть видна на этом экране:
пользователь может открыть конкретную серию вместо продолжения сохранённой. При изменении
верхнего уровня модель `PlaybackSourceSelectionModel` нормализует все зависимые значения и
не оставляет недоступный сезон, серию, озвучку или качество выбранными.

## Полноэкранный плеер

- Видео всегда полноэкранное; HUD накладывается поверх него на полупрозрачном тёмном фоне.
- OK при скрытом HUD показывает управление и не ставит воспроизведение на паузу.
- Left и Right при скрытом HUD выполняют шаг перемотки и открывают HUD с фокусом на
  таймлайне.
- Таймлайн не получает рамку фокуса. В сфокусированном состоянии текущая позиция отмечается
  белой точкой диаметром `12 dp`.
- Во время Media3 `STATE_BUFFERING` по центру показывается анимированный индикатор в тёмном
  круге. В режиме уменьшения анимации остаётся статическое кольцо.
- Нижняя строка содержит серии; отдельная дублирующая кнопка `Серии` не нужна.
- Управление сериями, сезоном, озвучкой, качеством, субтитрами и Web-fallback доступно из
  HUD обычным D-pad.
- После последней серии текущего сезона переход `Следующая серия` продолжает воспроизведение
  первой доступной серией следующего сезона по тем же правилам, что обычный переход между
  сериями.
- После естественного окончания фильма или последней доступной серии приложение
  возвращается в карточку материала, а не в каталог, экран выбора источника или выход из
  приложения.

Подробная событийная модель, media keys и resume-контракт описаны в
[`PLAYBACK.md`](PLAYBACK.md) и [`NATIVE_PLAYER_TV_UX.md`](NATIVE_PLAYER_TV_UX.md).

## D-pad anti-regression checklist

После изменения компоновки, размера или порядка focusable-элементов вручную проверить на
реальном TV:

- холодный старт оставляет видимый фокус на первом доступном постере;
- Up/Down в панели проходят по всем разделам, OK открывает раздел, активный пункт остаётся
  подсвеченным;
- Right из панели входит в контент, Left из первого столбца возвращается в панель;
- сетка предсказуемо перемещает фокус по шести колонкам и заранее подгружает следующую
  страницу из последней загруженной строки;
- Home: история остаётся одной строкой, переход вниз попадает в новинки;
- каталог: четыре вкладки, выпадающая сортировка и диалог фильтра полностью управляются
  пультом;
- поиск: Enter немедленно отправляет запрос, скрывает клавиатуру и переводит фокус в
  результаты;
- настройки: OK меняет значение, Left/Right только перемещают фокус, Left позволяет выйти в
  панель;
- карточка: постер виден, все действия и статусы достижимы, описание можно прочитать
  полностью;
- выбор источника: после смены озвучки доступны только её сезоны и серии, строка серии
  достижима;
- плеер: OK открывает HUD, Left/Right фокусируют таймлайн, точка текущей позиции видна,
  остальные кнопки достижимы без аэромыши;
- последняя серия сезона переходит в первую доступную серию следующего, а окончание
  последнего доступного материала возвращает в его карточку;
- Back из корневого раздела сначала показывает подтверждение выхода, а не закрывает
  приложение.

Сборка и Compose-тесты не заменяют эту аппаратную проверку. Непроверенные на TV изменения
фокуса нужно явно отмечать в [`PROJECT_STATE.md`](PROJECT_STATE.md).
