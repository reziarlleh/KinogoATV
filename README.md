# Kinogo TV

Kinogo TV — неофициальное нативное приложение-каталог и плеер для Android TV. Интерфейс
рассчитан на телевизор, горизонтальный экран и управление обычным пультом без сенсорного
ввода.

Текущая версия: **0.4.0-dev**. Поддерживается Android TV 9 и новее (API 28+).

## Возможности

- Каталог фильмов, сериалов и мультфильмов с шестиколоночной сеткой постеров, сортировкой,
  фильтрами по новинкам, году, стране и жанру и автоматической подгрузкой следующих
  элементов.
- Текстовый и системный голосовой поиск по каталогу с открытием полноценной карточки
  найденного фильма или сериала.
- Компактный стально-бирюзовый интерфейс, постоянное левое меню разделов, понятная подсветка
  фокуса и навигация D-pad-пультом.
- Полные описания, рейтинги и доступные сведения о качестве контента.
- Вход в аккаунт Kinogo и синхронизация серверных закладок:
  «Смотрю», «Смотрел», «Буду», «Бросил» и независимое «Избранное».
- Локальная история просмотра с сохранением фильма, сезона, серии и точной позиции.
- Продолжение просмотра с места остановки после перезапуска приложения.
- Проверка доступности встроенных адресов сервиса, автоматический выбор рабочего адреса и
  ручное добавление актуального HTTPS-зеркала.
- Выбор источника, озвучки, сезона, серии, качества и субтитров перед запуском и во время
  просмотра.
- Полноэкранный нативный Media3-плеер с единым полупрозрачным HUD, лентой серий,
  прогресс-баром, индикацией буферизации и графическими кнопками управления.
- Переход к следующей серии проходит через границу сезонов; после фильма или последней
  доступной серии приложение возвращается в карточку материала.
- Явный полноэкранный web-плеер для совместимых источников, когда пользователь выбирает этот
  вариант.
- Настройки качества по умолчанию, шага перемотки, субтитров, автоматического перехода к
  следующей серии, контрастности и уменьшения анимаций.
- Подтверждение выхода, защищающее от случайного закрытия приложения лишним нажатием
  «Назад».
- Фирменная тёмная плитка Android TV и отдельная launcher-иконка с отметкой `ATV`.

## Управление пультом

| Действие | Кнопка |
| --- | --- |
| Перемещение по меню, карточкам и спискам | D-pad |
| Открыть выбранный элемент | `OK` / `Enter` |
| Вернуться назад | `Back` |
| Показать скрытый HUD плеера | `OK`, `Up` или `Down` |
| Перемотать видео | `Left` / `Right` |
| Выбрать элемент HUD | D-pad + `OK` |
| Быстро перейти к серии | цифровые кнопки, если они есть на пульте |
| Воспроизведение, пауза, стоп, предыдущая/следующая серия | отдельные media-кнопки, если они есть |

При скрытом HUD первое нажатие `OK` только показывает управление. Нажатия `Left` и `Right`
сразу перематывают видео и переводят фокус на прогресс-бар для следующих нажатий.

## Установка

1. Разрешите установку приложений из неизвестных источников на Android TV.
2. Передайте подписанный APK на телевизор через USB-накопитель, файловый менеджер либо ADB.
3. Установите APK и запустите плитку **Kinogo TV**.
4. В разделе «Настройки» выполните проверку адресов сервиса. При необходимости добавьте
   доступное зеркало вручную.
5. Вход в аккаунт необязателен для каталога и просмотра, но нужен для синхронизации закладок.

Для обновления поверх установленной версии используется APK с той же подписью:

```powershell
adb install -r KinogoTV.apk
```

## Данные пользователя

История, настройки и закладки хранятся в данных приложения. Логин и пароль сохраняются только
на телевизоре в зашифрованном виде с ключом Android Keystore и используются для
автоматического восстановления сессии.

Приложение получает каталог и источники воспроизведения непосредственно во время работы,
поэтому ему требуется подключение к интернету.

## Если что-то не загрузилось

- Каталог недоступен — откройте «Настройки», запустите проверку адресов и выберите рабочий
  либо добавьте актуальный HTTPS-адрес вручную.
- Закладки не обновились — используйте «Синхронизировать» или «Переподключить» в блоке
  аккаунта.
- Источник воспроизведения истёк — вернитесь в карточку и снова нажмите «Смотреть», чтобы
  приложение заново получило доступные варианты.
- При раннем сбое приложение покажет диагностический экран, откуда можно повторить запуск
  или сохранить отчёт.
